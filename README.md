# NYC-Taxi-Lakehouse-A-Reproducible-Measured-Data-Platform-in-a-Box
Fully local, one-command lakehouse: kind + Terraform + Lakekeeper (Iceberg REST) + Spark on Kubernetes + Trino. Contract-validated ingestion with quarantine, an idempotent file ledger, Great Expectations checks, measured Iceberg benchmarks, and a verified teardown/rebuild acceptance check.
